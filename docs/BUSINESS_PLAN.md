# Muse Player 商业计划书

> 中国国际大学生创新大赛（2026）· 高教主赛道 · 本科生创意组

---

## 一、执行摘要

Muse Player 是一款面向大学生群体的 AI 情绪音乐推荐平台。用户用自然语言描述心情——"今天下雨了，有点emo"——系统通过 DeepSeek AI 理解情绪意图，从网易云、酷狗、QQ音乐、酷我等多平台聚合搜索匹配歌曲，以极光绿像素未来主义界面呈现推荐，并通过 Canvas 弹幕创造轻社交共听体验。

**核心价值**: 把"搜歌名"变成"说心情"，一个浏览器标签页替代四个音乐 App 的反复切换。

**当前状态**: 产品原型已完成（2669行单文件HTML），Demo Mode 支持零后端体验，PWA 可安装到桌面。

## 二、市场痛点与用户分析

### 2.1 痛点

| 痛点 | 现状 | Muse 方案 |
|------|------|-----------|
| 情绪搜索门槛高 | 需要知道歌名/歌手才能搜 | 用自然语言描述心情即可 |
| 平台碎片化 | 版权分散在4+平台，用户反复切换 | 一次搜索聚合4个平台 |
| 听歌孤独感 | 个人播放器缺乏互动 | 弹幕共听，情绪表达空间 |
| 推荐不够个性化 | 基于历史播放数据 | AI理解当下情绪+场景+偏好 |

### 2.2 目标用户

- **核心用户**: 18-25岁在校大学生
- **场景**: 宿舍独处、图书馆学习、运动跑步、通勤路上、深夜失眠、雨天发呆
- **规模**: 中国在校大学生约4000万人，音乐App渗透率>90%

### 2.3 用户画像

> 小李，大三，计算机专业。考试周压力大，想听点安静的学习音乐，但不知道搜什么。打开Muse，输入"在图书馆复习，需要专注"，AI推荐了 Weightless、Canon in D 等专注音乐，弹幕里飘过其他同学的评论——"同款复习BGM"。

## 三、产品介绍

### 3.1 核心功能

1. **自然语言情绪输入**: 用日常语言描述心情、场景、风格
2. **AI 情绪分析 + 推荐**: DeepSeek V4 理解意图，返回个性化推荐+推荐理由
3. **多平台聚合搜索**: 网易云 → 酷狗 → QQ音乐 → 酷我，自动回退
4. **弹幕共听体验**: Canvas实时渲染，歌词+网友情绪故事从右飘过
5. **种子扩散播放**: 播放一首歌后自动发现风格相似的歌曲，连续播放
6. **PWA 轻量部署**: 浏览器打开即用，无需安装App

### 3.2 视觉设计

极光绿（#40e0c0）像素复古未来主义，等宽字体+扫描线+呼吸光晕，独特的视觉识别。

## 四、技术架构

```
用户输入 → DeepSeek V4 (情绪分析+搜索关键词生成)
  → 多平台并行搜索 (网易云/酷狗/QQ/酷我)
  → 匹配分数过滤 (≥45分)
  → Agent 生成推荐卡片
  → Canvas 弹幕层实时渲染
  → 用户播放/反馈 → 种子扩散 → 循环
```

- **前端**: 纯 HTML/CSS/JS，单文件，零构建
- **AI**: DeepSeek V4 Flash (Chat Completions + Web Search)
- **音乐源API**: NeteaseCloudMusicApi + lx-music-api-server
- **弹幕**: Canvas 2D 实时渲染，性能优于 DOM 方案
- **存储**: 浏览器 localStorage，无服务端数据库

### AI 流程详解

```
1. 理解层: 自然语言 → 情绪标签 (mood) + 音乐类别 (genre) + 搜索关键词
2. 搜索层: 关键词 → 多平台并行/串行搜索 → 匹配分数过滤
3. 推荐层: 搜索结果 + 情绪语境 → AI 生成推荐理由 + 推荐卡片
4. 扩散层: 用户播放行为 → 种子歌曲 → 风格相似歌曲 → 自动预加载
5. 优化层: 用户跳过/完播 → 隐式反馈 → 下一轮推荐调整
```

## 五、商业模式

### 5.1 收入来源

| 模式 | 说明 | 阶段 |
|------|------|------|
| Freemium | 基础功能免费，高级AI推荐/VIP音质付费 | 中期 |
| 校园合作 | 与高校合作，定制校园音乐场景 | 中期 |
| 音乐人推广 | 独立音乐人付费推广新歌 | 远期 |
| 周边/联名 | 极光绿像素风周边产品 | 远期 |

### 5.2 成本结构

- DeepSeek API 调用费用（按token计费）
- 服务器/域名（GitHub Pages免费）
- 网易云API维护（开源项目）

| 多平台聚合 | ✅ 4平台 | ❌ | ❌ | ❌ |
| 弹幕共听 | ✅ | ❌ | ❌ | ❌ |
| 安装门槛 | ✅ 浏览器 | App | App | App |

## 八、风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 音乐版权 | 高 | 定位"发现推荐入口"非播放器；Demo使用Web Audio合成音景；引导用户去正版平台 |
| AI API成本 | 中 | 缓存常用推荐；优化prompt减少token消耗；探索本地模型 |
| 第三方API不稳定 | 中 | Demo Mode自动降级；多平台回退机制 |
| 竞品模仿 | 低 | 极光绿像素风品牌识别；数据积累护城河 |
| 用户隐私 | 中 | 全部本地存储；声明零数据收集；不追踪用户 |
