## 一、评委体验路径

### 路径 A：线上体验（推荐）

1. 访问 GitHub Pages 链接（见 README.md）
2. 页面自动进入 **Demo Mode**
3. 在右面板输入心情文字，例如："今天下雨了，有点emo"
4. 观察 AI 回复 + 推荐卡片出现
5. 点击 PLAY 试听
6. 观察弹幕效果
7. 体验完整交互流程

**无需 API Key，无需安装任何后端服务。**

### 路径 B：本地完整体验

1. 安装依赖并启动两个 API 服务
2. 设置 DeepSeek API Key
3. 登录网易云账号（可选，提升音质）
4. 体验完整 AI + 多平台搜索功能

## 二、Demo Mode 说明

Demo Mode 专为评委无障碍体验设计：

- **自动启用**: 本地 API 不可用时自动切换
- **内置数据**: 30+ 条歌曲、8 种情绪标签、模拟歌单
- **模拟搜索**: 根据输入关键词匹配内置数据
- **模拟播放**: 使用 CC0 免版权音频样本
- **弹幕演示**: 预置歌词和情绪故事
- **保留视觉**: 完整 UI 交互、像素风动画、弹幕效果

Demo Mode 不会调用 DeepSeek API（除非用户设置了 API Key），确保在任何网络环境下都能展示。

## 三、版权与合规声明

### 3.1 音乐版权

- **平台定位**: Muse Player 是"音乐发现、推荐与体验入口"，不是音乐播放器
- **播放源**: 所有音乐 URL 实时从合法 API 获取，平台不存储、不缓存任何音乐文件
- **Demo 音频**: 使用 Creative Commons Zero (CC0) 或免版税短音频样本
- **试听限制**: 仅提供短试听片段，引导用户前往正版平台

### 3.2 第三方代码

| 组件 | 来源 | 许可证 |
|------|------|--------|
| lx-music-api-server | [MeoProject](https://github.com/MeoProject/lx-music-api-server) | MIT |
| NeteaseCloudMusicApi | [Binaryify](https://github.com/Binaryify/NeteaseCloudMusicApi) | MIT |

两个第三方组件的完整许可证文件包含在对应目录中。

### 3.3 AI 使用声明

- 使用 DeepSeek API (deepseek-chat 模型)
- API Key 由用户自行提供，存储于浏览器 localStorage
- 不上传、不截获、不存储用户的 API Key
- AI 输出可能包含错误或不准确信息

### 3.4 数据隐私

- 全部用户数据（设置、播放列表、API Key）存储在浏览器 localStorage
- 无服务端数据库
- 无用户追踪、无分析 SDK、无广告
- 弹幕中的"网友故事"为 AI 生成或预置内容，不涉及真实用户数据

## 四、创新点总结

| # | 创新点 | 说明 |
|---|--------|------|
| 1 | **情绪→音乐的自然语言桥梁** | 不需要精确搜索词，用日常语言描述心情即可获得推荐 |
| 2 | **多平台聚合搜索 + 智能回退** | 一个输入覆盖 4 个音乐平台，自动选择可用源 |
| 3 | **弹幕式共听体验** | 将视频弹幕文化引入音乐播放，创造轻社交听歌空间 |
| 4 | **AI 种子扩散推荐** | 从一首歌自动发现风格相似的音乐，连续播放 |
| 5 | **极光绿像素未来主义** | 独特的视觉语言，在众多音乐 UI 中形成差异化记忆点 |
