# 3分钟演示视频脚本

> 目标: 在3分钟内展示问题→方案→产品→技术→价值

---

## 分镜表

### 0:00-0:25 | 问题场景
**画面**: 暗调画面，一个人在宿舍床上刷手机
**旁白**: "你有没有过这种感觉——心情不好，想听首歌，但打开音乐App，搜索框亮着，你却不知道打什么字？"
**画面**: 快速切四个音乐App图标：网易云、QQ音乐、酷狗、酷我
**旁白**: "就算知道歌名，还要猜它在哪个平台上。四个App来回切换，心情更差了。"

---

### 0:25-0:35 | 方案引入
**画面**: MUSE Logo 出现，极光绿光晕扩散
**旁白**: "如果听歌可以像聊天一样简单呢？Muse Player，用AI听懂你的心情。"

---

### 0:35-1:40 | 产品演示（核心1分钟）
**画面**: 浏览器打开 MUSE，Demo Mode 提示出现
**操作**: 在输入框输入"今天下雨了，一个人在宿舍，有点emo"
**画面**: AI 回复出现："我懂这种感觉。雨天适合慢下来..."
**画面**: 推荐卡片接连弹出：雨天咖啡馆、Rhythm of the Rain...
**操作**: 点击 PLAY
**画面**: 弹幕层启动——歌词 + 网友情绪故事从右飘过
**画面**: 左面板歌单更新，自动预加载下一首
**旁白**: "不需要搜歌名，不需要选平台。一句话，AI 帮你找到对的歌。弹幕里飘过的歌词和故事，让一个人听歌也不孤单。"

---

### 1:40-2:05 | Demo Mode + 零门槛
**画面**: 关掉所有后端服务
**操作**: 重新打开 index.html，直接可用
**旁白**: "最关键的——评委老师可以直接体验。我们内置了 Demo Mode，无需安装任何后端服务，浏览器打开就能完整体验核心功能。这就是 PWA 轻量部署的优势。"

---

### 2:05-2:40 | 技术架构
**画面**: 架构图动画
- 用户输入 → DeepSeek V4 → 多平台搜索 → 匹配过滤 → 推荐卡片
**旁白**: "技术架构上，我们建立了完整的AI推荐管道——从情绪理解到多平台聚合搜索，到匹配分数过滤，再到种子扩散推荐。这不仅是接了一个API，而是五个环节的AI工作流。"

**画面**: 四个平台Logo亮起（网易云/酷狗/QQ/酷我）+ 音质降级
**旁白**: "多平台自动回退和音质自适应，确保在任何条件下都能找到可播放的音源。"

---

### 2:40-3:00 | 结尾
**画面**: MUSE Logo + 极光绿背景
**字幕**: "让每一个心情都有音乐的回应"
**旁白**: "Muse Player。一个浏览器标签页，替代四个音乐App。我们不是要做另一个播放器，而是要重新定义——你如何找到你想听的歌。"
**画面**: GitHub二维码 + 联系方式
**旁白**: "谢谢各位评委老师。"

---

## 制作建议

- **工具**: OBS Studio 录屏 + 剪映/CapCut 剪辑
- **旁白**: 真人录音或AI配音（剪映/魔音工坊）
- **背景音乐**: Web Audio API 合成环境音景（与产品情绪匹配）
- **字幕**: 底部中文字幕，关键英文保留
- **分辨率**: 1080p 或 4K
