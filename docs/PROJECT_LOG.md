## 2026-06-10 — 美术优化方向讨论与预览确认

### 当前阶段
- 当前仍处于视觉方案讨论与预览阶段，尚未改动正式项目的核心功能。
- 已在 Codex 工作区生成多版页面预览图，用于讨论美术方向。
- 当前相对推荐的视觉方向为“极光玻璃数码钟 + 情绪文案 + 磨砂玻璃背景”的 MUSE 美术升级方案。

### 已生成的预览方向
- 初版美术增强：增强中心播放区、AI 对话区、底部播放控制区。
- AUTO 来源菜单版：将 `AUTO` 设计为点击后弹出来源菜单，包含 `AUTO / NCM / LX / WEB / DEMO`。
- 横向时钟版：取消右侧 M 转盘，将时钟横向放回主视觉区域。
- 像素时钟尝试版：尝试粗像素、细点阵像素，但用户反馈观感不佳，暂不采用。
- 当前推荐版：采用“极光玻璃数码钟”效果，替代像素时钟和右侧 M 转盘。

### 用户明确要求
- 保存原比赛提交版，不直接覆盖原版。
- 后续生成新的一版美术版本，但必须保留原版本可回退。
- 只改美术，不改核心功能。
- 不改搜索逻辑、播放逻辑、Demo Mode、AI 回复流程、API 来源逻辑和 localStorage 数据结构。
- 右侧转盘空间太小，不再使用带 `M` 的转盘作为主视觉。
- 时钟应横向展示，不放在右侧转盘位置。
- 像素风时钟多版尝试后观感不佳，当前暂定改用更好看的玻璃数码钟方案。
- 输入框上方不要使用产品简介式文案，改为 emotional 风格语句，可以带一点网络热梗或名言感。
- 当前示例 emotional 文案为：“今晚先别卷，雨声已经替你按下慢放。”
- `AUTO` 按钮应设计为点击后出现小菜单，用于切换搜索音乐来源。
- `WEB AUDIO SYNTHESIS` 下方频谱灯条应是会动的实时灯条，而不是固定装饰。
- 边框灯不应全部固定高亮，只有当前播放、Demo Mode、时钟、频谱等活跃状态可以轻微呼吸。
- `PWA READY` 和 `REASONED PICKS` 两项暂不改中文，保留英文。
- 可探索磨砂玻璃背景与低调景色背景，但背景不能突兀，不能抢主体内容。

### 当前推荐实装边界
- 建议先创建原版保护点：`v1.0-competition-baseline` tag 或备份分支。
- 新建美术分支：`visual-refresh-v1`。
- 实装范围限制在 CSS、布局结构、小型视觉组件和文案池。
- 如需时钟动态更新，可复用现有时钟能力，仅更换视觉表现。
- AUTO 菜单如正式接入，应复用现有来源选择逻辑，不新增搜索流程。
